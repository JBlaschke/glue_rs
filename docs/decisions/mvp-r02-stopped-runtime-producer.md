# Fixed stopped-runtime producer, source-only first episode

The decision draft preceded source implementation; this feature publishes the reviewed source. Add one distinct fixed backend/program class for an actual owned runtime recipe (existing TS binding2). Preserve all ordinary program bytes, APIs, defaults, public snapshot ABI and historical native proof rosters. Do not change TS or adopt a runner/controller/native kit now. Admission remains empty.

The fixed source protocol is defined by `runtime_stopped_trace.h`, the C formatter, and the independent `runtime_stopped.py` byte template. The program retains full target v2 phases and selected owner proc_info/wait4/wait4_nocancel/kill phases, with23 closed selector/action classes. Only first successful selected execve/new-image lwp gets raise(SIGSTOP17); later execs remain observed and incomplete for the first reader. Mach stop(), ptrace, process-grab, copyout, arbitrary predicates/templates/callbacks and caller trust booleans are absent.

Owner callID occupies headerdetail; childdetail remains ppid. Owner returns20/21 carry original scalar outcomes and fixed176/4-byte TRACEMEM payloads;22 is kill scalarreturn;23 safely retains unexpected-query/wait outcomes without copying unsafe bytes. Leading/trailing zero-size DIFEXPR/RAISE records are exact grammar members. Newkind counts and live selected identities have separate storage/getter/schema; old snapshot refuses only this newclass. Getter fields come from validated already-serialized raw callbacks, retain exact outer ordinals/newTID/markeridentity, and become unusable after faults/drops/output failures.

Timestamps differ per ECB and precede copyin completion. All outer ordinals/hash remain intact; explicit callID and raw entry/return brackets correlate ownerbuffers. The next selected ownerentry/intendedCONTentry bounds completion. RawkillCONT is only a conditional intendedrequest, not resumption or retention proof. Existing GLUEPX01 is unchanged; absent wait-pointer binding remains explicitly source-conditional.

Pinned XNU implements raise through deferred AST and enforces the global destructive gate plus process privileges. COPYIN additionally checks kernel/proc privilege and scratch/fault safety. Normal restrictive public SIP cannot admit this destructive profile. The consumer option does not relax global CSR/code signing. No provider, signal, ptrace, VM, protection or privileged native action runs in this source milestone.

Source-only controls must cover independent canonical program bytes/oldprofile differentials; exact23 selector/action descriptors and all refusals; singleton initialmarker; ownercallID lifecycle and capturedbytes including opaque/error/fallback; actualserialized identityprefix and invalidation; pure getters and oldsnapshot ABI; drop/fault/cleanup/deadlines; and closed non-Darwin support. Models do not grant native calibration. No current policy consumer, raw capture acceptance, output exemption, state feed, quiescence/OFD/generation or general runtime adoption follows.


## Original-byte reader integration

The separate `pair_runtime_stopped_raw` entry consumes one original physical
stream, eight unchanged runtime recipe assets and the original4096-byte GLUEPX01
packet. Its private physical codec adds only the new closed action layouts to
the unchanged owned decoder. Shared bounded transport preserves every outer
ordinal and separates child attachment position from owner record position.
The marker must follow the selected exec-success in original serialized order;
timestamp ties do not bypass the producer's success latch. Both valid orders of
the ordinary lwp-start and marker remain accepted.

Owner calls pair by original thread/call ID/probe identity. Query results retain
all176 bytes; waits retain all4 bytes, including opaque failed/zero-return data.
The next selected same-thread owner entry bounds completion of the preceding
copy. No equality join between independent ECB timestamps or affine conversion
between C monotonic and DTrace clocks is assumed. GLUEPX has no wait-buffer
pointer, so the wait join remains source-conditional. Complete transport and
recipe validation precede the diagnostic result, including late failures.

The new factory and typed prefix remain unadopted by the current TS coordinator,
runner and registered kits. No continuation sidecar or caller-normalized capture
is accepted. Raw kill means an intended request only; file retention before
continuation, successful signal delivery, native origin, quiescence, backing
identity, state admission, output exemption and full acceptance remain unproved.
Normal restrictive SIP does not admit this destructive native profile; no SIP
change or provider execution is part of this source feature.

Publication also updates the runtime FD policy's exact recipe-helper identity
for this reviewed common implementation. Its v1/v2/v3 public scopes and result
shapes remain unchanged. Existing serialized default facts compare byte-for-byte
with the original helpers. Historical proof rosters and native admission are
unchanged. CI adds the two focused reader/producer suites; portable hosts retain
actual unavailable-factory checks and explicit SDK-only skips.
