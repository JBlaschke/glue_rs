# R02: fixed stopped-runtime FD-policy projection

Status: reviewed source feature, 29 October 2026. The decision draft preceded code. Root approved the design
with no output seeds and a request-only diagnostic-gap path. This is source
policy adoption, not controller/native or output authorization.

A separate fixed original-byte factory calls the approved stopped reader once,
then privately projects child FD/fcntl/F_GETFL intent from its complete outer
capture and associated images. Preserve every owner/child/Mach/auxiliary phase,
original outer ordinal/hash, pair index and image/thread epoch. Owner controls
have distinct indexes and never become child FD operations. No filtered capture
is constructed, no raw public API is replayed, and no cross-ECB timestamp equality
or native-clock mapping is assumed.

Extract a neutral private evaluator and paired/unpaired attempt projection from
the existing policy engine. Its three old factories still format exactly their
existing classes/scopes/defaults/error behavior. The new fixed module accepts
only original program/probe/error/events/contract, the stopped reader's exact
eight-asset evidence class, and original 4096-byte GLUEPX. No caller capture,
operations, policy flags or future C CONT record is accepted.

Use no output seeds in the new projection. Complete correlated input can receive
existing finite conditional FD rules; every exec still retires certainty and
opaque effects remain sticky from ENTRY. GLUEPX matching never supplies a
binding, flag, alias, generation, backing, live-state or sink grant. Raw CONT is
only a conditional intended cut. Before/after-cut writes remain unexempt.

Any diagnostic gap produces requests/accounting only: no fabricated outcome,
successful window, transition or state prefix, even if child images remain
partially associated. Original pairs/outcomes remain in the retained diagnostic
source. All diagnostic gaps, forbidden requested intents and original phases
remain visible. Native/origin/retention/OFD/generation/backing/live-state/output/
state-feed/full claims stay false. Full macOS coverage remains open.

Preserve frozen original source and unchanged old test bytes and meaningful exact-serialization differential
oracles, run unchanged 36+27+16 controls plus focused original-byte stopped-policy
controls under both Python versions, and retain pilots/source hashes. No reader,
recipe, C source, native closure, actual worktree, Git, provider, VM or SIP action
belongs to this change. Root owns peer review, later PR and CI.

Implemented validation: the unchanged 36/27/16 old methods and 19 focused methods
pass under Python 3.15.2 and 3.9.6, 98 each/196 total, zero skips. Twenty-one complete
serialized old-profile results (including Mach fallback, four-scalar/status scope
differences and sticky horizons) and 12 early/late refusals match actual frozen
62556cff execution. The new path checks one stopped pass, no legacy public
reparse, no output seeds, original pair/image/thread/outer indexes, request-only
diagnostic failures, touching child windows, second-exec gap and authority-free
immutable results. Test-only pilots remain in local evidence. Original JSON
lines are retained by the approved reader's whole-byte digest/count, not copied
into the policy result. No C or native test is applicable or performed.
