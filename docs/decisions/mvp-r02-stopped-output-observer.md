# Stopped owned-child output observer, source milestone v1

The observer acquires an actual SIGSTOP child wait status and retains eight original vnode FD queries. It performs no stop, continue, ptrace, provider, descriptor mutation or publication. This is a conditional observation, not native admission, quiescence/OFD/descriptor-generation proof, sink exemption, state authority or retroactive authorization.

Use an opaque single-owner context initialized with the actual fork child, two still-held original output references, the original cooperative monotonic deadline, request/catalog/READY/program bindings, sequence, raw exec ordinal/new TID and the complete original GLUERW01 bytes. The constructor reads the actual parent SIGCHLD policy (SIG_DFL, no SA_NOCLDWAIT); no other reaper/controller or concurrent mutation is permitted by source contract. Native support is fixed Darwin LP64 little-endian only; non-Darwin fails ENOTSUP. The native factory recomputes the original GLUERW SHA256 through CommonCrypto and rejects a declared mismatch. The library does not impose a parent UID restriction; controlled unprivileged same-UID execution is a test-fixture restriction, not an observer API restriction. Injected operations exist only in an explicitly test-compiled constructor and grant no native claims.

One poll calls actual waitpid(child, ..., WNOHANG|WUNTRACED). Zero/EINTR may retry within the original deadline and finite 64-call journal. Exact SIGSTOP acceptance consumes the sampling attempt before further callbacks. Terminal waits and ECHILD retire ownership before the fallible after-clock. Stop notification does not reap. Failure is permanent; no failed sample is replayed. A final monotonic check after the final owner/policy guard precedes conditional-match publication; header lastclock retains that check, which may follow the eighth query after-time. Ownership is observational only: callers must still perform their separate bounded cleanup and never signal a retired PID. Deadline checks cannot interrupt blocked syscalls.

After accepted stop, query in this order: parent held stdout/stderr round1, child fd1/fd2 round1, child fd1/fd2 round2, parent held stdout/stderr round2. All use PROC_PIDFDVNODEINFO and eight distinct stable original 176-byte buffers. Check native size, each field offset/width, little-endian LP64 and constants against the SDK at compile time. The explicit logical codec converts every field, including pad/spare bit patterns, to big-endian. An incomplete return retains the entire original buffer as opaque; it is never decoded as a partial successful row.

The conditional matcher requires DTYPE_VNODE/VREG, regular single-link distinct stdout/stderr backing, raw FWRITE set and FREAD/FEXEC absent, child PROC_FP_CLEXEC clear and parent held CLEXEC set. Stable backing, access and relevant descriptor/guard policy must agree across samples; offsets/timestamps and PROC_FP_SHARED do not establish stability or OFD identity. All raw flags remain retained. Compare the original GLUERW backing using signed32 vst_dev sign-extension to uint64; do not compare stale pre-exec full status flags. The native factory and strict Python reader each recompute the original binding/hash; injected model constructors remain explicitly untrusted and C source inputs are not authentication. Unsupported file-status bits (guarded/close-on-fork), guard flags and unknown raw open flags refuse. The supported raw open mask is FMASK0x404000cf plus observed FWASWRITTEN0x10000; compare FMASK only.

GLUEPX01 is exactly 4096 bytes: header [0,256), eight query rows [256,2048), 64 wait rows [2048,4096). All integers are BE; wire reserved bytes and unread rows are zero.

Header: magic0:8; u16 version8=1/headerbytes10=256; u32 bytes12=4096,owner16,child20; u64 sequence24,deadline32,execordinal40,newTID48; u16 querycount56,waitcount58,state60,reason62; i32 errno64; u32 flags68; u64 lastclock72; u16 accepted wait index80 (one-based), errorcount82; reserved84:96; SHA256 request96,catalog128,READY160,program192,originalGLUERW224. Flags are owned1,accepted-stop2,sampling-attempted4,conditional-match8,reaped16,ownership-lost32. States are active1,complete2,refused3,reaped4,lost5.

Each 224-byte query row: u32 pid0; i32 fd4; u64 before8,after16,original-buffer-address24; i32 API-return32,saved-errno36; u16 flags40; u8 role42 (stdout1/stderr2),round43 (1/2); reserved44:48; 176-byte payload48. Flags: attempted1,complete-field-codec2,opaque-failure4,valid-after-clock8. Query count includes issued calls; failure-before-call leaves no fabricated row. All issued calls retain their original buffers, including complete calls followed by a clock failure.

Each 32-byte wait row: u64 before0,after8; i32 returnedPID16,original-status20,saved-errno24; u32 flags28. Flags: attempted1,valid-after-clock2,terminal4,ECHILD8,accepted-SIGSTOP16,status-valid32. Status bytes from other outcomes are retained opaque. Every issued wait appears once, even zero/EINTR. A failed after-clock retains the already-observed lifecycle effect.

The pure Python reader takes exact complete packet and original GLUERW bytes, strictly checks framing/counts/reserved/row order/bindings and recomputes conditional backing consistency. All native-origin, raw correlation, quiescence, state, exemption, full-flags proof and full trace acceptance flags remain false. It feeds no current policy consumer or raw producer.

Focused injected controls cover all fields, short/zero/oversize returns, raw flags/device conversion, prefixes, clocks, actual-wait ownership transitions and no replay, canonical bytes and malformed packets. A separate unprivileged same-UID exec-child fixture may self-SIGSTOP; its parent calls the helper, SIGCONT and reaps with explicit cleanup. It does not grant general provider/runtime acceptance. Existing APIs/headers/producers/registries/CI remain unchanged in this milestone.
