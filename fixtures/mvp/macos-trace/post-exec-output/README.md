# Stopped owned-child output observations

This source milestone records an actual owned-child SIGSTOP wait and eight original PROC_PIDFDVNODEINFO results. It has no stop, continue, signal, ptrace, provider, descriptor mutation or integration API. Existing bootstrap/trace profiles are unchanged. All native-origin, raw-correlation, quiescence, OFD/generation, state, exemption and full-trace admission remain false.

`px_observer_new` copies immutable bindings and complete original GLUERW01 bytes into an opaque context. The Darwin LP64 little-endian factory recomputes the original witness SHA256, checks actual parent SIGCHLD default/no-SA_NOCLDWAIT policy, and uses only fixed native operations. It supports a privileged bootstrap parent without changing privileges. Native tests separately require an unprivileged same-UID controlled fixture. Non-Darwin native construction returns ENOTSUP. `PX_TESTING` exposes a separate injected model constructor, never a production profile selector; its declared digest is independently checked by the Python reader.

The source-selected caller owns the exact fork child, retains the original held outputs, excludes every other reaper/controller and concurrent policy/FD mutation, and supplies the launch attempt's original monotonic deadline and clock domain. Actual wait acquisition establishes a child wait relationship, not this entire history or an exclusive suspension lease. Ordinary SIGSTOP cannot by itself prove quiescence or rule out external continue/restop.

`px_observer_poll` performs one waitpid with WNOHANG|WUNTRACED. Zero/EINTR can be retried by the caller within the original deadline and 64-call journal. Exact Darwin SIGSTOP status0x117f consumes the single sampling attempt before any later callback. Terminal wait or ECHILD retires ownership before the fallible after-clock. A stop does not reap. A final clock check follows the final owner/policy guard before publishing a match; header.last_clock retains that check. Every failed or completed sample refuses replay. The helper never sleeps, resumes, signals or cleans up a child; cooperative checks cannot interrupt blocked calls. The caller remains responsible for bounded cleanup of only its actual unreaped owned PID.

Sampling uses eight distinct stable original176-byte destinations: parent stdout/stderr round1; child fd1/fd2 round1; child fd1/fd2 round2; parent stdout/stderr round2. Every successful complete result is encoded field by field as BE, including all pad/spare bit patterns. Incomplete results retain all176 initialized destination bytes opaque. Completed prefix rows and buffers survive failure; unread rows stay zero. SDK size, every native field offset/width and constants are compile-checked. No native struct memcpy is used as the successful portable encoding.

The conditional matcher compares single-link regular distinct output backing, write-only internal FWRITE2 with FREAD1/FEXEC0x40000000 absent, fixed file/vnode type1, parent PROC_FP_CLEXEC2 set and child clear. Only SHARED1/CLEXEC2 status bits are supported; guard/close-on-fork/unknown status or nonzero guard words refuse. It supports raw FMASK0x404000cf plus observed FWASWRITTEN0x10000, compares FMASK and retains every bit. Shared indicators, mutable offsets/timestamps, spare/pad values and FWASWRITTEN do not prove identity or stable history. vst_dev high bits are sign-extended from signed32 into the old TFO uint64 domain. Existing F_GETFL/O_WRONLY1 and F_GETFD/FD_CLOEXEC1 domains are not conflated with native proc fields.

`px_observer_encode` emits the exact4096-byte GLUEPX01 original prefix: header256, eight224-byte query rows,64 wait rows of32 bytes. The [decision](../../../../docs/decisions/mvp-r02-stopped-output-observer.md) specifies each offset, enum and flag. `decode_observation(packet, original_witness)` accepts only complete immutable bytes and independently verifies original hash/bindings, canonical rows/order, actual wait shape, prefixes and conditional backing consistency. Valid caller sequence/epoch/TID/program/address declarations remain unauthenticated; a packet cannot establish their raw correlation. Failed packets remain failed even when some metadata agrees. There is no current consumer, raw producer or retroactive write authorization.

Run the focused controls with `python3 test_post_exec_output.py`. `GLUE_PX_TEST_RETAIN` selects a new persistent directory and `GLUE_PX_TEST_SANITIZE=1` enables ASan/UBSan. Injected controls establish source/model behavior only. The sole native fixture execs its own same-UID child with two private regular outputs; the child self-SIGSTOPs, the helper consumes that wait and queries, then the test parent continues and actually reaps it. The fixture uses synthetic request/READY/old-witness bindings around actual controlled file metadata; it proves neither the real bootstrap path nor provider/raw/admission acceptance. Only the still-owned child can receive bounded failure-cleanup SIGKILL, never after terminal wait/ECHILD.
